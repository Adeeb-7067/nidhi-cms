# Satyakabir Technologies — Cinematic Scroll

Next.js UI-only cinematic website for **Satyakabir Technologies**. Scroll-scrubbed frame animation, mock enterprise content, and a premium dark brand system from the official SK logo.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
